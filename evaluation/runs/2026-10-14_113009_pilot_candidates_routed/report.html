However, XOR is not linearly separable: no single threshold can separate the input pairs (0,1) and (1,0) (which should output 1) from (0,0) and (1,1) (which should output 0) using a linear decision boundary. This limitation was demonstrated in the lecture, showing that XOR requires a two-layer network combining "A and not B" with "not A and B" using inhibitory (negative) weights. [GAIF-2.5]
